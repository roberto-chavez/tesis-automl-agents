# Datasets grandes: muchas imágenes

Con más de unas 10000 imágenes de entrenamiento se pueden considerar arquitecturas de mayor capacidad como ResNet50V2 o ConvNeXtTiny, siempre que los recursos lo permitan. El riesgo de sobreajuste baja, por lo que el dropout puede ser bajo de 0.0 a 0.2 y el aumento de datos es opcional.
